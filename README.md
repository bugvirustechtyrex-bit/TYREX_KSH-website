# TYREX_KSH TECH Store — Heroku Ready

## Files
- index.html — website
- style.css — design
- server.js — Node.js web server
- package.json — Node/Heroku configuration
- Procfile — Heroku web process

## Run locally
```bash
npm start
```

## Heroku
Deploy this repository as a Node.js app. Heroku will run:

`web: node server.js`

The website listens on Heroku's `$PORT` automatically.
